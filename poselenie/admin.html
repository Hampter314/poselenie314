Структура администрации

Отдел по работе с населением

Работа с обращениями граждан, социальные вопросы, взаимодействие с общественными организациями.

Отдел ЖКХ и благоустройства

Организация водоснабжения, содержание дорог, благоустройство территории, вывоз ТКО.

Бухгалтерия

Ведение бухгалтерского учёта, составление отчётности, исполнение бюджета поселения.

Специалист по земельным вопросам

Учёт земель, работа с кадастровыми документами, аренда муниципального имущества.
